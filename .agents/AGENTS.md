# AI Assistant Rules

- **Cleanup Temporary Files**: Always delete any temporary scripts, scratch files, or AI-generated artifacts (such as `update_*.js`, `.py` scripts, or `.txt` tracking files) immediately after the task or feature implementation is successfully completed. Do not leave temporary files in the workspace.
- **Update Release Notes on Deploy**: Whenever committing and deploying changes (via `/deploy` or user instruction), always prepend a new entry to `window.PASSION_MAP_RELEASES` in `release-notes.js` with `id` incremented by `+1`, `date` (`YYYY-MM-DD`), `tags` (array of feature category labels such as `'畝CAD・図面'`, `'栽培計画'`, `'マップ・圃場'`, `'作業画面'`, `'スケジュール'`, `'出退勤・休憩'`, `'農薬・資材'`, `'市況・原価'`, `'機械・車両'`, `'看板・ピン'`, `'天気・環境'`, `'お知らせ・システム'`), and `message` (the commit message without `Manual: `), and update `release-notes.js?v=...` in `worker.html`, `worker2.html`, and `admin.html` (plus `cacheBust` in `schedule.html`) before running `git add .` and `git commit`.
