【作業完了報告】栽培計画モーダルの大幅なUI改修・機能拡張が完了しました。

■ 修正内容
1. 重複していた「年度」入力を1つに統合し、プルダウンリスト化しました。
2. カレンダーの表示期間を12ヶ月から18ヶ月（1月〜翌年6月）に拡張しました。
3. モーダル上部に「作型を行に追加」ボタンとペイントツール（播種・定植・収穫・消しゴム）を配置しました。
4. 単一のテーブルで、作型ごと（品種ごと）に動的に行を追加し、ペイントツールで自由に期間を選択できる UI アーキテクチャに書き換えました。
5. 推定収穫量や定植面積などは、行の構成に従って正しく表示・計算されるようにアップデートしました。

■ 実施済みテスト
- Node.js の Function コンストラクタによる schedule.html 内の JS 構文チェックを通過し、構文エラーがないことを確認済みです。
- 置換用の一時スクリプト（rearchitect_modal.js）は正常に削除しました。
